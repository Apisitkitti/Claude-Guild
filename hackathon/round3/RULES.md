# ⚔️ Claude Guild AI Hackathon รอบ 3 — กติกา (เข้มข้น)

ผู้แข่ง: Sonnet 4 ทีม · Red team: Opus 1 · กรรมการ: Opus 3 (A ผลิตภัณฑ์ · B วิศวกรรม · C เกมดีไซน์)

## ด่าน
1. **Pitch** — `pitch-teamN.md`
2. **Cross-examination** — red team อ่านโค้ดจริงแล้วเขียนข้อกล่าวหาทุกทีม (`redteam.md`)
3. **Rebuttal** — แต่ละทีมตอบทุกข้อกล่าวหา: ยอมรับ + แก้แผน หรือ หักล้างด้วยหลักฐาน (`rebuttal-teamN.md`)
4. **Judging** — กรรมการตรวจข้ออ้างกับโค้ดเองทุกข้อที่สำคัญ (`judge-X.md`)

## ข้อบังคับ pitch
- ห้ามเสนอสิ่งที่มีแล้ว: Territory Clash + ดวล, Lookout Bell (คิว/ลูป/กระดิ่ง), mana bar, MCP/แชร์ข้ามเครื่อง (พักไว้)
- เครื่องเดียว, hook เป็น async (เตือนได้ ขวางไม่ได้)
- **ทุกข้ออ้างเรื่องข้อมูล** ต้องอ้างหลักฐาน: `file:line` ในโค้ด หรือฟิลด์ใน hook payload ที่ store รับจริง — ถ้าเป็นการเดา ต้องเขียนว่า "สมมติฐาน"
- ต้องมี: ตัวชี้วัดความสำเร็จ (วัดได้) + เกณฑ์ยกเลิก (kill criterion)
- MVP ≤ 400 บรรทัด, ระบุไฟล์ + รายชื่อ test
- กฎ canvas: ตัวละครห้ามโปร่งใส/ย้อมสี, ห้ามวาดของโปร่งใสทับตัวละคร, ข้อความไทยต้องอ่านง่าย

## การให้คะแนน (ต่อกรรมการ)
Base = 2×Impact + Delight + Feasibility + Theme + Risk (1-10, เต็ม 60, Risk 10 = เสี่ยงต่ำ)
- **หัก −3** ต่อข้ออ้างเรื่องข้อมูล/โค้ดที่กรรมการตรวจแล้ว **ไม่จริง** และไม่ได้ติดป้าย "สมมติฐาน"
- **หัก −2** ต่อข้อกล่าวหาของ red team ที่ rebuttal ไม่ตอบหรือตอบเลี่ยง
- **บวก +2** (สูงสุด +4) เมื่อ rebuttal แก้แผนได้ดีขึ้นจริงจากข้อกล่าวหา
- **ตัดสิทธิ์ (0)** ถ้าแกนหลักของฟีเจอร์พึ่งข้อมูลที่ไม่มีจริง
- คะแนนต่ำสุด 0 ต่อกรรมการ · เสมอ → ตัดสินที่ Impact รวม แล้วจึง Risk รวม
