# Judge C — กรรมการสายเกมดีไซน์ (รอบ 3 เข้มข้น)

**มุมมอง:** ฟีเจอร์ต้องเข้ากับแฟนตาซีกิลด์ อ่านออกในพริบตาบนแคนวาสที่แน่นอยู่แล้ว น่ารักแต่ไม่รก เคารพกฎแคนวาส (ตัวละครห้ามโปร่งใส/ย้อมสี ห้ามวาดของโปร่งใสทับตัว ข้อความไทยต้องอยู่ใน DOM ≥12px เพราะ `WORLD_FONT` บนแคนวาสเล็กมาก) และไม่ชนระบบเดิม ให้คะแนนจาก**แผนฉบับแก้** และดูว่าแก้แล้วเสน่ห์ยังเหลืออยู่ไหม
ภาษาภาพที่มีอยู่แล้ว: เหนือหัวมีบับเบิล ❗/🔁 (`lib/office/render.ts:1579-1584`) ไอน้ำ berserk ห่างข้างหัว ≥11px (`:1356-1365`) HP pips ของดวล (`drawHpBar` `:882`) badge `+N` · NPC ที่เคาน์เตอร์สั่นกระดิ่ง (`:1434-1450`) · พร็อพ "ledger, bell, candle" บนเคาน์เตอร์ (`:357`) · พาเนลมี 4 ส่วนแล้ว ได้แก่ 🔔 คิว / นักผจญภัย / อาณาเขต / log (`components/OfficeApp.tsx:604-728`)

**สูตร:** Base = 2×Impact + Delight + Feasibility + Theme + Risk (Risk 10 = เสี่ยงต่ำ) · −3 ต่อข้ออ้างข้อมูล/โค้ดที่ผมตรวจแล้วไม่จริงและไม่ได้ติดป้าย "สมมติฐาน" · −2 ต่อข้อกล่าวหาที่ตอบเลี่ยงหรือไม่ตอบ · +2 ต่อการแก้แผนที่ดีขึ้นจริง (สูงสุด +4) · ไม่ตัดคะแนนเลขบรรทัดที่คลาดไป 1-6 บรรทัดถ้าเนื้อหาตรงจุดนั้นจริง

## รายทีม

### ทีม 1 — Receipt Ledger (49)
- **ตรวจข้ออ้าง:** ข้ออ้างหลักจริงทั้งหมด ได้แก่ `slim` ย่อ object ชั้นลึกเป็น `"{…}"` (`lib/store.ts:275`) ทำให้ `todos[]` ใช้ไม่ได้, dedupe ด้วย `tool_use_id` (`lib/attention.ts:214-219`), `TaskUpdate` (`lib/office/engine.ts:479`) · `failed =` ที่อ้างไว้ `:204` จริง ๆ อยู่ `:210` แต่เนื้อหาตรง จึงไม่หัก · ตัวนับ Todo ติดป้ายสมมติฐานไว้แล้ว
- **เลนส์เกม:** เข้ากับกิลด์ที่สุดในรอบนี้ เป็น "ใบรายงานเควสต์" ที่ให้รางวัลกับผลลัพธ์ ไม่ใช่กับการ grind และผูกกับพร็อพ ledger บนเคาน์เตอร์ได้ฟรี · แถว `📄3 ✅1 📦2` อ่านออกในพริบตาและเงียบ · ไอคอน "ฟื้น test" ต้องใช้ช่องบับเบิลเดิมแบบ `tempBubble` ห้ามซ้อนเป็นชั้นใหม่เหนือ ❗/🔁 และห้ามโผล่ขณะดวล (ที่นั่นเป็นของ HP pips)
- **แผนแก้ยังมีเสน่ห์ไหม:** มีเสน่ห์มากขึ้น แผงใหม่ "เพิ่งเสร็จ" ที่ใบเสร็จยังอยู่หลังนักผจญภัยออกจากโถงไปแล้ว = กระดานรายงานเควสต์ ตรงคำถาม "ตอนกลับมาที่โต๊ะ" เสียไปแค่ subject ของ commit
- **โบนัส +4:** R1-1 เก็บใบเสร็จที่ปิดแล้วแยก TTL 2 ชม. + cap 30 (แก้แกนปัญหาของตัวเอง) และ R1-3 นิยาม "ฟื้น" ระดับ runner + cwd
- **ข้อเสนอ:** ใบเสร็จที่ปิดแล้วให้เปิดจากสมุดบนเคาน์เตอร์ ไม่ต้องเพิ่มส่วนที่ 5 ในพาเนล และไม่ให้แสดงไอคอนเมื่อตัวนับเป็น 0

### ทีม 2 — Cartographer's Atlas (37)
- **ตรวจข้ออ้าง:** ไม่พบข้ออ้างที่ไม่จริง Grep `path` ติดป้ายสมมติฐานไว้ ส่วนการอ้าง client/sim เป็นหลักฐานที่อ่อน (ทีมยอมรับเองใน R2-2) · dedupe ที่อ้าง `:207-216` จริงอยู่ `:214-219` ไม่หัก
- **เลนส์เกม:** แนวคิดนักทำแผนที่กับ 🌑 "ดินแดนที่ยังไม่สำรวจ" (fog of war) เป็นแฟนตาซีชั้นดี แต่ของที่จะทำจริงคือตารางใน DOM
- **แผนแก้ยังมีเสน่ห์ไหม:** เสียไปมาก ทีมถอดการ highlight ตัวละครออกทั้งหมด (R2-3) ซึ่งปลอดภัยต่อกฎแคนวาส แต่โลกกิลด์ไม่มีอะไรเกิดขึ้นเลย และสัญญาณ Confusion ยังพิสูจน์ไม่ได้ว่าแยกออกจากไฟล์ hub
- **โบนัส +2:** R2-1 ใช้ baseline เทียบ median + hub-list และ blind label (R2-4 เป็นงานความปลอดภัยที่ต้องทำอยู่แล้ว)
- **ข้อเสนอ:** เพิ่มลูกศรทึบเหนือหัวเมื่อคลิก (ใช้ช่องเดียวกับ ❗) หรือม้วนแผนที่ที่ผนังโถง

### ทีม 3 — Permission Tax (38)
- **−3:** pitch อ้างว่า "เก็บเฉพาะ fingerprint+label สั้น … กันความลับรั่วลงไฟล์" แต่ label คือ 80 ตัวแรกของคำสั่งดิบ (`lib/attention.ts:127`) ใส่ `Bearer` token ได้ และ `.gitignore` ไม่มี `.guild/` (ตรวจแล้ว)
- **เลนส์เกม:** แนว "เจ้าหน้าที่เก็บภาษี" เข้ากับกิลด์พอได้ แต่ไม่มีอะไรอยู่บนแคนวาส เป็นตาราง DOM ที่วางติดกับ 🔔 คิว ผู้ใช้จะเห็นสองแผงที่พูดเรื่อง permission ซ้อนกัน · ตัวเลข "≤/~ นาที" อ่านในพริบตายาก เพราะคนจะถือเป็นค่าจริง
- **แผนแก้ยังมีเสน่ห์ไหม:** ใช้งานได้จริงขึ้นมาก (เสนอ rule เฉพาะตอนปลอดภัย, demo ใช้คำสั่งที่รันสั้น) แต่ไม่ได้น่ารักขึ้นเลย
- **โบนัส +4:** R3-2 แยกการปิด wait 2 แบบ + ประมาณเวลาปฏิกิริยาคนจาก tool ที่รันเร็ว และ R3-3 ไม่เก็บคำสั่งเลย เก็บแค่ rule string
- **ข้อเสนอ:** รวมเป็นแถวพับใต้ 🔔 คิว (เช่น "💸 ภาษีวันนี้") แทนการเพิ่มส่วนใหม่ในพาเนล และให้ปุ่ม Copy เป็น "ใบอนุญาตตราประทับ"

### ทีม 4 — Sentinel Ledger (37)
- **−3:** pitch อ้างว่า "mask ที่ tracker ก่อนเข้า snapshot; evt … ผ่าน slim อยู่แล้ว" ซึ่งไม่จริง เพราะ `slim` เก็บ 300 ตัวแรกไว้ (`lib/store.ts:273`) แล้ว broadcast ผ่าน SSE (`:313`) และใส่ใน snapshot (`:319-322`) · การอ้าง `:30`/`:32` ที่คลาดไป 1 บรรทัดไม่หัก
- **เลนส์เกม:** "ยามเฝ้าประตู" เข้ากับธีม แต่ไอคอน 🛡 "ข้างหัว" แย่งช่องเดียวกับไอน้ำ berserk (`render.ts:1356-1365`) และแดงซ้อนกับ ❗/🔁/clash ทำให้ห้องที่มีหลาย session ดูแดงไปหมด · มีหลายระดับ (🔴🟠🟡) บวกกระดิ่งเดิม = noise
- **แผนแก้ยังมีเสน่ห์ไหม:** noise ลดลงจริง (เตือนจาก Post เท่านั้น, เตือนครั้งเดียวต่อชุด edit, ยกเว้น build dir) และ redaction ใน `addEvent` อุดรูรั่วของระบบเดิมให้ทุกคน แต่ภาพบนแคนวาสยังไม่ได้แก้
- **โบนัส +4:** R4-1 redact ก่อน slim/SSE/log และ R4-2 เปลี่ยนเป็นเตือนจาก PostToolUse เท่านั้น (ไม่กล่าวหาเมื่อผู้ใช้ deny)
- **ข้อเสนอ:** ตัด 🛡 บนตัวละคร ใช้ยามที่ประตูโถงยกโล่แทน (วาดครั้งเดียว ไม่แตะตัวละคร) และแสดงเฉพาะ 🔴
