## เช็กกับภาษาภาพเดิม (สั้น ๆ)
- พื้นที่เหนือหัวแน่นแล้ว: bubble (สูง 17px) → badge ดาบไขว้/VS (`render.ts:673` วาง `ICON_UP` และเลี่ยงชนแบบ `iconBlocked`) → HP pips ของดวล (`drawHpBar`, `DUEL_PIPS=3`) — อะไรที่จะเพิ่มเหนือหัวต้องเข้าคิวเดียวกันนี้ ไม่ใช่ซ้อนชั้นใหม่
- มี "พลังชีวิต" อยู่แล้ว 2 แบบ: หัวใจ `MAX_HEARTS=3` ใน roster และ HP pips ตอนดวล → เพิ่ม HP ชุดที่ 3 = สับสน
- `cleric` เป็นคลาสนักผจญภัยอยู่แล้ว (`sprites.ts`, เวทสีทอง `HOLY_COLS`) → NPC นักบวชจะถูกอ่านผิดเป็น "session อีกตัว"
- บนเคาน์เตอร์โถงมี "ledger, bell, candle" วาดอยู่แล้ว (`render.ts:357`) → ทั้งกระดิ่ง (ทีม 3) และสมุดบัญชี (ทีม 2) มีพร็อพรอให้ผูกฟรี
- `WORLD_FONT` บนแคนวาส 6.5px → ข้อความไทยยาว ๆ บนแคนวาสอ่านไม่ออก ต้องอยู่ DOM

## ทับซ้อน: ทีม 1, 3, 4 = ตัวจับลูป/ติดหล่มตัวเดียวกัน
ทั้งสามใช้ fingerprint `tool_name+tool_input` + `PostToolUseFailure` + ตัวตรวจฝั่ง server แบบ `TerritoryTracker` แทบเหมือนกัน ต่างกันแค่ "ห่อด้วยภาพอะไร" และขอบเขต: ทีม 1 = ลูปอย่างเดียวแต่ลึก (เทียบ response hash ว่าผลเปลี่ยนไหม — ฉลาดสุด), ทีม 3 = ลูป + "Claude ถามคุณอยู่" + context รวมเป็นคิวเดียว, ทีม 4 = 6 อาการรวมสุขภาพคน (กว้างสุด รกสุด)
**อุปมาไหนอ่านง่ายสุด:** Berserk ชนะขาด — ตัวละครเดิมเปลี่ยนท่าทาง/ตาแดง/ฟาดลมเร็วขึ้น อ่านออกจากอีกฝั่งห้องโดยไม่ต้องมีป้าย และ "คลั่ง = ทำซ้ำไม่ได้ผล" ตรงความหมาย; Lookout Bell อ่านง่ายใน DOM แต่บนแคนวาสเป็นแค่ไอคอน; Infirmary ต้องอธิบาย (นักบวชเดินมาทำไม? ใครป่วย?) และชนกับคลาส cleric

## ความเห็นรายทีม

### Team 1 — Berserk Watch (46)
- **จุดแข็ง:** อุปมาดีที่สุดของรอบ — สถานะเป็น "ตัวละคร" ไม่ใช่ป้ายแปะ; มอนสเตอร์ตัวเดิมไม่ตาย + `x4` ผูกกับระบบล่ามอนที่มีอยู่อย่างแนบเนียน; response hash แยก "วน" กับ "คืบหน้า" ได้จริง; เขียนกฎแคนวาสมาถูก (เฟรมใหม่ทึบ ไม่ tint)
- **จุดอ่อน:** เฟรมคลั่งต้องวาดครบ 5 คลาส × หลายท่า (งานพิกเซลใหญ่กว่า M); Rage meter 5 ช่องเหนือหัวแย่งที่เดียวกับ HP pips ดวล 3 ช่อง → คนจะคิดว่ากำลังดวล; แดง/🔴 ซ้ำกับระดับ clash; แบนเนอร์ "BERSERK ฟาดลงจอ" ถ้าเกิดบ่อยจะกลายเป็นเสียงรบกวน
- **ข้อเสนอ:** ตัด meter เหนือหัว ใช้ "ไอน้ำเดือด/เส้นเลือดปูด" พิกเซลทึบ 2-3 จุดข้างหัว + เฟรมเดียวต่อคลาส; banner แค่ครั้งแรกที่ขึ้นระดับ Berserk; ห้ามเข้าดวลขณะคลั่ง

### Team 2 — Mana Ledger (41)
- **จุดแข็ง:** ปลอดภัยต่อแคนวาส 100% (DOM ล้วน) ไม่ชนอะไร; ต่อยอด mana bar เดิมตรง ๆ; ปัญหา auto-compact/cache หลุดเป็นของจริง
- **จุดอ่อน:** เป็น dashboard (sparkline, ตารางท็อป 5, cache hit %) ที่หลุดแฟนตาซี — ไม่มีอะไรเกิดในโลกกิลด์เลย; "พยากรณ์ ~14 turn" บนการ์ดเป็นตัวเลขเพิ่มอีกตัวในการ์ดที่แน่นแล้ว
- **ข้อเสนอ:** ให้ mana bar เองเล่าเรื่อง: ขีดพยากรณ์บนแถบ + ขวดยาแตกเมื่อ cache หลุด; ตาราง Ledger เปิดจากสมุดบนเคาน์เตอร์ที่มีอยู่แล้ว

### Team 3 — Lookout Bell (47) — ผู้ชนะของกรรมการ C
- **จุดแข็ง:** อ่านง่ายและเงียบที่สุด — ข้อความไทยอยู่ใน DOM ≥12px, บนแคนวาสใช้ไอคอนทึบ pattern เดียวกับ ❗; คิวเดียวรวม "ใครต้องการฉัน" ตอบโจทย์หลาย session ตรงที่สุด; "💬 Claude ถามคุณอยู่" เป็นสัญญาณใหม่ที่ไม่มีใครเสนอ; ปุ่ม `N` เป็น game-feel ที่ดี
- **จุดอ่อน:** delight บนแคนวาสน้อย — เป็นเครื่องมือมากกว่าเกม; ไอคอนเหนือหัวเพิ่มอีกชั้นต้องเข้าคิว `iconBlocked` กับ badge ดาบไขว้; ชื่อ "Lookout" แต่ไม่มียามให้เห็น
- **ข้อเสนอ:** ทำให้มี "ยาม" จริง — ใช้ NPC ที่เคาน์เตอร์ (`NPC_POS`) สั่นกระดิ่งที่วาดอยู่แล้วเมื่อคิวมีแถวแดง; และ **ยืมภาพ Berserk ของทีม 1** มาแทนไอคอน 🔁 สำหรับสถานะลูป (เฟรมเดียว/คลาส)

### Team 4 — Infirmary (39)
- **จุดแข็ง:** ภาพนักบวชวิ่งมาร่ายเวทน่ารักและเป็นเรื่องเล่า; ใบวินิจฉัย + ปุ่ม copy ใช้ได้จริง; รับข้อติดรอบ 1 มาดี (ตรวจฝั่ง server, เตือนไม่ขวาง)
- **จุดอ่อน:** NPC นักบวช vs คลาส cleric = อ่านผิด; HP bar ใน roster ซ้ำกับหัวใจที่มีอยู่ (สุขภาพชุดที่ 3); 6 อาการ + ชวนพัก + คำสั่งเสี่ยง = เตือนพร่ำ ตัวละครครึ่งห้องจะมีไอคอนพร้อมกัน; NPC เดินข้ามห้องไปหาคนป่วยต้องหาทางเดินผ่าน duel arena/plot
- **ข้อเสนอ:** ตัดเหลือ loop + failure streak; ใช้หัวใจเดิมลดลงแทน HP ใหม่; ให้ NPC เป็นหมอผี/หมอยาที่หน้าตาต่างจากคลาสชัด ๆ
